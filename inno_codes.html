Invoice AI Installer Return Codes

This document describes the return codes that may be returned by the Invoice AI Windows installer.

Return Code Meaning
0 Installation completed successfully
1 Installation failed or was terminated
2 Installation was cancelled
Other An unexpected installer error occurred

The Invoice AI installer uses Inno Setup. If an unexpected return code is encountered, please contact the Invoice AI developer for assistance.
